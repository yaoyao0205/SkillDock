# UI Audit

## 审查维度

- 信息层级：一屏之内是否能看出主次。
- 间距系统：是否复用同一套 4/8 倍数间距。
- 对比度：正文与背景对比是否达到 4.5:1。
- 交互反馈：悬停、点击、禁用、空态是否齐全。

## 输出

以表格给出：问题、优先级、依据、修改建议、预期效果。不要只描述“看起来不舒服”，要说明违反了哪条规则。
