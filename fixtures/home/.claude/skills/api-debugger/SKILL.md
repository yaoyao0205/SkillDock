# API Debugger

## 什么时候用

- 联调时后端返回 401/404/500，但不确定问题出在网关、鉴权还是业务代码。
- 返回体字段与文档不一致，需要快速给出最小复现请求。

## 步骤

1. 复述请求：方法、路径、鉴权方式、关键 header 与 body。
2. 逐层验证：DNS → 网关 → 服务 → 依赖（DB/缓存/第三方）。
3. 输出最小 curl 复现命令，标出预期与实际差异。
4. 给出修复建议，并说明需要哪一方改动。

## 输出格式

- 现象一句话
- 证据（状态码、响应片段、日志行）
- 最可能原因（按概率排序）
- 下一步验证动作
