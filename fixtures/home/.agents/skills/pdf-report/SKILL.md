# PDF Report

## 输入

- 数据表（CSV / XLSX / JSON）
- 报告受众与页数上限
- 必须出现的结论或指标

## 结构

1. 封面：标题、日期、数据口径
2. 摘要：三段以内讲清楚结论
3. 正文：图表 + 解读，图表下方标注来源
4. 附录：明细数据与字段说明

## 排版规则

- 正文使用 10.5pt，行距 1.6。
- 每页只讲一个主题，图表不超过两个。
- 数字统一千分位，百分比保留一位小数。
